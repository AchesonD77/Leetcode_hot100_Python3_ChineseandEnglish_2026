# 答案：
```python
# 交叉节点法
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        # 判断是否为空
        if not head:
            return None
        
        # 第一次遍历，复制节点并插入到原始节点后面
        cur = head # 定义一个指针
        while cur:
            copy = Node(cur.val)
            copy.next = cur.next
            cur.next = copy
            cur = copy.next
        
        # 第二次遍历，复制random。此时的链表已经是 A->A' 这样的
        cur = head # 定义一个指针
        while cur:
            copy = cur.next
            if cur.random:
                copy.random = cur.random.next
            cur = copy.next

        # 第三次遍历，将合并的链表拆分为两个。
        cur = head
        copy_head = cur.next

        while cur:
            copy = cur.next
            cur.next = copy.next

            if copy.next:
                copy.next = copy.next.next
            cur = cur.next
        return copy_head
```

# 一、题目描述

给你一个特殊的链表。

每个节点包含两个指针：

- `next`：指向下一个节点
- `random`：可以指向链表中的任意节点，也可以指向 `None`

例如：

```
7 → 13 → 11 → 10 → 1
```

其中：

```
13.random → 7

11.random → 1

10.random → 11

1.random → 7
```

要求：

> **复制整个链表（Deep Copy），并返回复制后的链表头节点。**

要求：

- 新链表与原链表完全独立
- next 相同
- random 相同
- 不允许 random 指向原链表

思想：

```

```

这是 Google、Meta、字节、腾讯等公司最喜欢考的方法。

# 二十六、完整 LeetCode 代码（★★★★★）

```python
class Solution:

    def copyRandomList(self, head):

        if not head:
            return None

        # 第一次遍历：复制节点并插入原节点后面
        cur = head

        while cur:

            copy = Node(cur.val)
            copy.next = cur.next
            cur.next = copy

            cur = copy.next

        # 第二次遍历：复制 random
        cur = head

        while cur:

            copy = cur.next

            if cur.random:
                copy.random = cur.random.next

            cur = copy.next

        # 第三次遍历：拆分链表
        cur = head
        copy_head = head.next

        while cur:

            copy = cur.next

            cur.next = copy.next

            if copy.next:
                copy.next = copy.next.next

            cur = cur.next

        return copy_head
```

def copyRandomList(head):

    if not head:

    cur = head

    while cur:

        copy = Node(cur.val)

    while cur:

        cur.next = copy.next

        if copy.next:

# 三十一、最终总结

穿插节点法的核心思想只有一句话：

> **复制节点永远紧跟在原节点后面。**

整个算法分为三步：

```
第一次遍历
↓
复制节点并插入原节点后面

↓

第二次遍历
↓
利用 cur.random.next 建立 random

↓

第三次遍历
↓
拆分链表
↓
恢复原链表
↓
得到复制链表
```

必须牢记的四句核心代码：

```python
copy.next = cur.next
cur.next = copy

copy.random = cur.random.next

cur.next = copy.next
copy.next = copy.next.next
```

这道题不仅考察**链表操作能力**，更重要的是考察**利用已有结构替代额外空间**的思想。理解了这一题，你会真正掌握 **"空间换时间" 与 "结构设计"** 的经典算法思想，这也是很多高级链表题和系统设计题中的常见技巧。
