# 一、题目描述

给你一个链表的头节点 `head`，请将链表按照 **升序排序**，并返回排序后的链表。

例如：

```
输入：

4 → 2 → 1 → 3

输出：

1 → 2 → 3 → 4
```

再例如：

```
输入：

-1 → 5 → 3 → 4 → 0

输出：

-1 → 0 → 3 → 4 → 5
```

# 十二、LeetCode 核心模板（前半部分）

```python
class Solution:

    def sortList(self, head):

        # 递归终止，如果为空
        if not head or not head.next:
            return head

        slow = head
        fast = head.next

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        mid = slow.next
        slow.next = None

        left = self.sortList(head)
        right = self.sortList(mid)

        # 后面 讲 merge()
        return self.merge(left, right)
```

# 二十、Merge 函数完整代码（★★★★★）

```python
def merge(self, l1, l2):

    dummy = ListNode(0)
    cur = dummy

    while l1 and l2:

        if l1.val < l2.val:
            cur.next = l1
            l1 = l1.next

        else:
            cur.next = l2
            l2 = l2.next

        cur = cur.next

    if l1:
        cur.next = l1

    if l2:
        cur.next = l2

    return dummy.next
```

# 二十三、完整 LeetCode 代码（★★★★★）

```python
class Solution:

    def sortList(self, head):

        # 递归终止
        if not head or not head.next:
            return head

        # 快慢指针找中点
        slow = head
        fast = head.next

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 断开链表
        mid = slow.next
        slow.next = None

        # 递归排序左右两部分
        left = self.sortList(head)
        right = self.sortList(mid)

        # 合并
        return self.merge(left, right)

    def merge(self, l1, l2):

        dummy = ListNode(0)
        cur = dummy

        while l1 and l2:

            if l1.val < l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next

            cur = cur.next

        if l1:
            cur.next = l1

        if l2:
            cur.next = l2

        return dummy.next
```

# 二十五、涉及到的 Function 讲解

## 1. ListNode()

**作用：** 创建新的链表节点。例如：`dummy = ListNode(0)` 创建虚拟头节点，方便统一处理链表。

---

## 2. merge()

**作用：** 将两条已经升序排列的链表合并成一条新的升序链表，这是归并排序中的 **Merge** 阶段，也是 LeetCode 21 的经典模板。

---

## 3. sortList()

**作用：** 使用递归不断拆分链表，直到每段只有一个节点，再调用 `merge()` 将左右两部分重新合并，实现整个归并排序。
