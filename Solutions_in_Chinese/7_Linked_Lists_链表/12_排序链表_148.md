# LeetCode 148. 排序链表（Sort List）——（归并排序思想）

答案：
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 判断递归终止条件，递归时这里return 值是我们需要的
        if not head or not head.next:
            return head
        
        # 递归方法，快慢指针找中点
        slow = head
        fast = head.next
        
        # 开始循环移动，每次移动：慢指针移动一步，快指针会移动两步
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 找到中点(慢指针的下一位为中点)，断开连接
        mid = slow.next
        slow.next = None # 前后从中间分开成两条链

        # 进行递归排序
        # "先把 head 这段链表全部排好序，等排完以后，把排好序的链表返回给 left。"
        left = self.sortList(head)
        right = self.sortList(mid)

        # 在返回的 时候调用merge进行合并（此时进行排序）
        return self.merge(left, right)


    # 单独写merge方法函数
    def merge(self, l1, l2):

        # 虚拟指针
        dummy = ListNode(0)
        # 当前指针
        cur = dummy

        # 开始循环同时比较两个链表
        while l1 and l2:
            if l1.val < l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            
            cur = cur.next
        
        # 当跳出循环，某个链表为空的时候，这里是l1非空，l2为空的情况
        if l1:
            cur.next = l1
        if l2:
            cur.next = l2

        return dummy.next
```

# 一、题目描述

给你一个链表的头节点 `head`，请将链表按照 **升序排序**，并返回排序后的链表。

例如：

```
输入：

4 → 2 → 1 → 3

输出：

1 → 2 → 3 → 4
```

再例如：

```
输入：

-1 → 5 → 3 → 4 → 0

输出：

-1 → 0 → 3 → 4 → 5
```

# 十二、LeetCode 核心模板（前半部分）

```python
class Solution:

    def sortList(self, head):

        # 递归终止，如果为空
        if not head or not head.next:
            return head

        slow = head
        fast = head.next

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        mid = slow.next
        slow.next = None

        left = self.sortList(head)
        right = self.sortList(mid)

        # 后面 讲 merge()
        return self.merge(left, right)
```

```python
def merge(self, l1, l2):

    dummy = ListNode(0)
    cur = dummy

    while l1 and l2:

        if l1.val < l2.val:
            cur.next = l1
            l1 = l1.next

        else:
            cur.next = l2
            l2 = l2.next

        cur = cur.next

    if l1:
        cur.next = l1

    if l2:
        cur.next = l2

    return dummy.next
```

# 二十三、完整 LeetCode 代码（★★★★★）

```python
class Solution:

    def sortList(self, head):

        # 递归终止
        if not head or not head.next:
            return head

        # 快慢指针找中点
        slow = head
        fast = head.next

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 断开链表
        mid = slow.next
        slow.next = None

        # 递归排序左右两部分
        left = self.sortList(head)
        right = self.sortList(mid)

        # 合并
        return self.merge(left, right)

    def merge(self, l1, l2):

        dummy = ListNode(0)
        cur = dummy

        while l1 and l2:

            if l1.val < l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next

            cur = cur.next

        if l1:
            cur.next = l1

        if l2:
            cur.next = l2

        return dummy.next
```

# 二十五、涉及到的 Function 讲解

## 1. ListNode()

**作用：** 创建新的链表节点。例如：`dummy = ListNode(0)` 创建虚拟头节点，方便统一处理链表。

---

## 2. merge()

**作用：** 将两条已经升序排列的链表合并成一条新的升序链表，这是归并排序中的 **Merge** 阶段，也是 LeetCode 21 的经典模板。

---

## 3. sortList()

**作用：** 使用递归不断拆分链表，直到每段只有一个节点，再调用 `merge()` 将左右两部分重新合并，实现整个归并排序。

# 归并排序最重要的一句话
递归负责拆，Merge负责排。

                sortList(4 2 1 3)
                      │
                   不断拆分
                      │
        ┌─────────────┴─────────────┐
        │                           │
      4 2                         1 3
      │ │                         │ │
      4 2                         1 3
        ↑                           ↑
      return                      return
        │                           │
      merge                       merge
      ↓                             ↓
     2 4                          1 3
        \                         /
         \                       /
          \      merge          /
           ────────────────────
                    ↓
              1 -> 2 -> 3 -> 4


"merge() 要求 l1、l2 已经有序，可我从来没有给它排序啊，它们为什么突然有序了？"

答案就是：

不是当前这一层把它们排好序的，而是更深一层递归已经排好了，然后 return 回来的。

把 head 这一整段链表彻底排好序以后，再把结果返回给 left。

left = self.sortList(head)

left =
"等待下面所有递归完成"

↓

得到

已经排好的左链表

sortList() 从来没有直接排序整个链表，它只做两件事：

把链表拆到不能再拆（单节点天然有序）。
每一层递归返回时，都调用 merge()，把两个已经有序的子链表合并成一个更大的有序链表。

所以，真正让 l1、l2 有序的，不是当前这一次 merge()，而是更深一层递归中的 merge()。
整个排序过程发生在**递归返回（回溯）**阶段，而不是递归向下拆分阶段。理解了这一点，你就真正理解了归并排序。

# 四十三、算法总结（★★★★★）

**归并排序（Merge Sort）是链表排序的最佳选择。**

整个算法只有四步：

```
快慢指针找中点
↓
断开链表
↓
递归排序左右两部分
↓
Merge 合并两个有序链表
```

必须牢记的四段核心代码：

① 找中点

```python
slow = head
fast = head.next

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

② 断开链表

```python
mid = slow.next
slow.next = None
```

③ 递归排序

```python
left = sortList(head)
right = sortList(mid)
```

④ Merge

```python
while l1 and l2:

    if l1.val < l2.val:
        cur.next = l1
        l1 = l1.next
    else:
        cur.next = l2
        l2 = l2.next

    cur = cur.next

cur.next = l1 if l1 else l2
```

最终复杂度：

| 项目 | 复杂度 |
|------|--------|
| 时间复杂度 | **O(n log n)** |
| 空间复杂度（递归版） | **O(log n)** |
| 空间复杂度（Bottom-Up 非递归版） | **O(1)** |
