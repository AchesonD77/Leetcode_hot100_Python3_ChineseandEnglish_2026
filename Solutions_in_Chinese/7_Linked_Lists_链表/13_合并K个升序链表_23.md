# LeetCode 23. 合并 K 个升序链表（Merge K Sorted Lists）

---

Part 1（题目分析 + Divide & Conquer 思想）

# 一、题目描述
![alt text](<../../Snap_for_Questions/7_Linked_Lists_链表/截屏2026-07-13 17.22.04.png>)

给你一个链表数组 `lists`，其中每一个链表都已经按照 **升序排列**。

请将所有链表合并成一条新的升序链表，并返回新的头节点。

例如：

```
输入：

[
1 → 4 → 5,
1 → 3 → 4,
2 → 6
]
```

输出：

```
1 → 1 → 2 → 3 → 4 → 4 → 5 → 6
```

---

# 九、为什么 Divide & Conquer 更快？（★★★★★）


越来越长。

越来越慢。

完全不同。

例如：

# 十、本题整体流程（★★★★★）

Divide & Conquer：

整体流程只有四步：

```
将 K 个链表分成左右两部分
↓
递归合并左半部分
↓
递归合并右半部分
↓
调用 merge() 合并两个有序链表
```

是不是又看到了：

```
148
```

其实只是：

对象变了。

148：

```
拆节点
```

23：

```
拆链表数组
```

Merge：

完全一样。
